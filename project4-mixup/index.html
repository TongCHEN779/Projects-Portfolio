Buddy mixup: pull every point toward its nearest enemy

Ordinary mixup blends random pairs. Here every point gets a deterministic buddy — the nearest point with a different label — and moves toward it by at most half the distance, so labels never swap. Drag the mixup slider and watch the SVM decision boundary move with it.

How it works

1 · Buddies. For each point xi find b(i) = argminj: yj≠yi ‖xi−xj‖. Brute force is O(n²). Here each class gets a k-d tree, and every point queries the tree of the other class, giving O(n log n) on average (the worst case degrades but is rare for 2-D data). For high dimensions you would swap in an approximate-nearest-neighbour index.

2 · Move. x′i = xi + t · ½ · (b(i) − xi), labels unchanged. At t = 1 a point stops exactly at the midpoint to its buddy, so it never crosses into the other class's side of that pair. Unlike random mixup, the direction is deterministic and always points to the nearest decision-relevant neighbour — near the boundary points move a little, far from it they hardly move at all in absolute terms, so the clouds shrink toward the margin from both sides.

3 · Train. An RBF-kernel SVM is trained on the moved points with an SMO solver (second-order working-set selection) running entirely in your browser. “Test accuracy” is measured on a fresh, un-mixed sample from the same generator with the same noise.

Things to try. Raise the noise so the classes overlap and see whether mixup tightens or distorts the boundary; use two circles with a small inner radius; push C up and watch the boundary overfit single noisy points, then see how mixup changes that.
